## 🤖 للمطورين — API جاهز

<div align="center">

**واجهة متوافقة 100% مع OpenAI — غيّر الرابط والمفتاح بس وأدواتك الحالية تشتغل فورًا**

</div>

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://malg-ai.onrender.com/api/malg/v1",
    api_key="MALG_API_KEY",   # اعمل مفتاحك من داخل المنصة
)

res = client.chat.completions.create(
    model="malg-ai",
    messages=[{"role": "user", "content": "اكتبلي سكريبت بايثون يرتب ملفاتي"}],
)
print(res.choices[0].message.content)
```

<details>
<summary>🔧 مثال cURL — اضغط للعرض</summary>

```bash
curl https://malg-ai.onrender.com/api/malg/v1/chat/completions \
  -H "Authorization: Bearer $MALG_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "malg-ai",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

</details>

<details>
<summary>🛠️ شغّله في Cline أو OpenCode — اضغط للعرض</summary>
